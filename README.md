# AI-Driven-Phishing-Email-Detection
AI-Driven Phishing Email Detection is an NLP-based machine learning project that classifies emails as safe or phishing. It combines TF-IDF text features with structural metadata and compares Logistic Regression, Random Forest, Naive Bayes, and MLP models, achieving 97.05% accuracy and 0.9755 F1-score with MLP.
